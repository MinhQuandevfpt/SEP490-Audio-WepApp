## Notes

1. **TC-RETURN-001 to TC-RETURN-005**: Test cases for viewing return history list, including pagination, empty state, loading, and error states.

2. **TC-RETURN-006 to TC-RETURN-011**: Test cases for viewing latest return request card and various display scenarios (with/without images, with/without package info).

3. **TC-RETURN-012 to TC-RETURN-019**: Test cases for submitting package information, including validation rules for weight and dimensions based on product specifications.

4. **TC-RETURN-020**: Test case for viewing return requests with different statuses and their corresponding UI elements.

5. **Weight Validation Rules**:
   - If product weight <= 5kg: Package weight cannot exceed product weight + 0.3kg
   - If product weight > 5kg: Package weight cannot exceed product weight * 1.15 (15% increase)
   - Package weight cannot be less than product weight

6. **Dimensions Validation Rules**:
   - Each dimension (length, width, height) cannot be less than product dimension
   - Each dimension cannot exceed product dimension + 2cm

7. **Status Flow**: PENDING → APPROVED → (packaging) → SHIPPING → RECEIVED → REFUNDED/AUTO_REFUNDED. Alternative paths: REJECTED, CANCELLED.

8. **Auto-approval**: If shop doesn't respond within 48 hours, status changes from PENDING to APPROVED with `autoApproved=true`.

9. **Auto-cancellation**: If customer doesn't submit package info within 72 hours after APPROVED, status changes to CANCELLED.

10. **Auto-refund**: If shop doesn't process return within 48 hours after receiving item (trackingStatus='delivered'), status changes to AUTO_REFUNDED.
