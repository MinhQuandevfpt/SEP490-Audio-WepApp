## Notes

1. **TC-CAMPAIGN-001 to TC-CAMPAIGN-005**: Test cases for Admin creating campaigns, including validation for time constraints and flash slots.

2. **TC-CAMPAIGN-006 to TC-CAMPAIGN-008**: Test cases for Admin updating campaign status, including allowed transitions (DRAFT → ONOPEN, any → DISABLED) and restrictions (cannot manually set ACTIVE/EXPIRED).

3. **TC-CAMPAIGN-009 to TC-CAMPAIGN-010**: Test cases for Admin viewing and deleting campaigns.

4. **TC-CAMPAIGN-011 to TC-CAMPAIGN-013**: Test cases for Seller viewing available and joined campaigns.

5. **TC-CAMPAIGN-014 to TC-CAMPAIGN-015**: Test cases for Seller joining campaigns with product registration.

6. **TC-CAMPAIGN-016 to TC-CAMPAIGN-020**: Test cases for Admin approving/rejecting campaign products.

7. **TC-CAMPAIGN-021 to TC-CAMPAIGN-025**: Test cases for Customer viewing Flash Sale and Mega Sale campaigns and products.

8. **Campaign Status Flow**:
   - DRAFT → ONOPEN (Admin manually) → ACTIVE (Scheduler at startTime) → EXPIRED (Scheduler at endTime)
   - Any status → DISABLED (Admin manually, emergency stop)

9. **Flash Sale Slots**: Flash Sale campaigns require at least 1 slot. Slots cannot overlap and must be within campaign time range.

10. **Product Approval Flow**: Seller registers products → Status DRAFT → Admin approves → Status APPROVE → Status ACTIVE (when campaign starts) → Status EXPIRED (when campaign ends).

11. **Time Validation**: 
    - Start time cannot be in the past (for create)
    - End time must be after start time
    - Flash slots must be within campaign time range
    - Cannot modify times if campaign has started

12. **Customer View**: Only campaigns with status ACTIVE are visible to customers. Only products with status APPROVE or ACTIVE are displayed.
